# YouTube Live Chat Filter

YouTube のライブ配信およびチャットリプレイにおいて、コメントをフィルタリングできる Google Chrome 拡張機能です。  
「自分と配信者（＋許可した特定ユーザー）のコメントだけを表示する（ホワイトリスト）」、または「指定した特定ユーザーのみを隠す（ブラックリスト）」を用途に合わせて選択できます。

---

## 主な機能

* **2つのフィルタ方式**
  * **ホワイトリストモード（デフォルト）**: 自分・配信者・許可したユーザー以外のコメントをすべて非表示にします。コメントの流れが速い配信で自分の発言や配信者の反応を追いたい場合に適しています。
  * **ブラックリストモード**: 指定した特定ユーザーのコメントのみを非表示にします。スパムや不快なコメントを個別にブロックしたい場合に適しています。
* **生配信・チャットリプレイ（アーカイブ）両対応**
  * ライブ配信中はもちろん、配信終了後のチャットリプレイでも同様にフィルタリング機能を利用できます。
* **配信者ごとの設定自動保持**
  * 許可ユーザー・ブロックユーザーの設定は、配信者ごとにブラウザのローカルストレージへ独立して保存されます。
* **柔軟な配信者・モデレーター判定**
  * 配信者バッジ（オーナーバッジ）による自動検出に対応。
  * 設定により「モデレーターを配信側として扱う（常に表示）」ことも可能です。
* **Manifest V3 完全準拠**
  * 最新の拡張機能仕様に適合しており、高速かつ安全に動作します。

## インストール手順

本拡張機能は、Chrome の「デベロッパーモード」を利用して読み込みます。

### 1. ファイルの準備
* GitHub の Releases から最新の `youtube-live-chat-filter.zip` をダウンロードして解凍するか、本リポジトリをダウンロード（またはクローン）します。

### 2. Chrome への登録
1. Google Chrome を開き、アドレスバーに `chrome://extensions/` と入力して拡張機能の管理画面を開きます。
2. 画面右上にある **「デベロッパーモード」** のスイッチを ON にします。
3. 画面左上に表示される **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
4. 解凍したフォルダ（またはリポジトリ内）にある **`extension`** フォルダを選択します。
5. ツールバーの拡張機能一覧（パズルピースのアイコン）に「YouTube Live Chat Filter」が追加されたら完了です。

## 使い方

### 1. 自分のチャンネルの登録
1. 拡張機能のアイコンをクリックしてポップアップを開きます。
2. 「自分のチャンネル」入力欄に、ご自身のチャンネル URL、ハンドル（`@handle`）、またはチャンネル ID（`UC...`）を入力して「保存」をクリックします。

### 2. フィルタの利用
1. YouTube のライブ配信（またはアーカイブのチャットリプレイ）ページを開きます。
2. 拡張機能ポップアップを開き、トグルスイッチを ON にします。
3. **ホワイトリスト時**:
   * 自分と配信者のコメント以外が非表示になります。
   * チャット発言者一覧から「許可」ボタンを押すと、そのユーザーのコメントも表示されるようになります。
4. **ブラックリスト時**:
   * チャット発言者一覧から「ブロック」ボタンを押したユーザーのみが非表示になります。

### 3. 設定項目
* **フィルタ方式**: ホワイトリスト / ブラックリスト の切り替え。
* **モデレーターを配信側として扱う**: ON にすると、モデレーターのコメントが常に表示対象になります。
* **起動時の動作**: ページ読み込み時に「毎回OFFで開始」するか「前回の状態を復元」するかを選択できます。

## 開発・パッケージ化

配布用の ZIP アーカイブを生成するためのバッチファイルが同梱されています。

```cmd
package.bat
```

上記コマンドを実行すると、`extension/` フォルダ内の必要なファイルのみを抽出し、`dist/youtube-live-chat-filter.zip` を自動生成します。
